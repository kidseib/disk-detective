# Privacy policy

**Effective date:** November 26, 2026

Disk Detective is a local Windows program. It does not collect, transmit, sell, or share personal information.

## What stays on your computer

Disk Detective runs entirely on your PC. It has no server, no telemetry, no analytics, and no internet connection. Your file names, folder paths, scan results, and reports stay on your computer.

## Local data the app stores

- **Settings:** the last selected drive and text-size choice are stored in `%LOCALAPPDATA%\DiskDetective`.
- **Trash:** removed items are moved to a hidden `.diskdetective-trash` folder on the same drive so they can be put back.
- **Move history:** records of cross-drive moves are stored in the app's local data folder so moves can be checked, repaired, or undone.
- **Reports:** if you choose **Save a report**, the app writes a standalone HTML file wherever you choose. It can contain file names and folder paths, so review it before sharing it.

## Network and third parties

Disk Detective does not make network connections. It does not use cloud services, accounts, advertising, or third-party analytics at runtime.

The app is downloaded from GitHub and may be code-signed by SignPath Foundation in future releases. Those services are involved only in distribution and signing, not in running the app or handling your files.

## Administrator mode

Choosing **Restart as administrator** lets the app see Windows folders that are normally hidden. It does not enable data collection or network access.

## Children and sensitive data

Disk Detective is a general-purpose storage utility. It does not knowingly collect information from anyone, including children.

## Changes

If this policy changes, the updated version will be published in this repository with a new effective date.

## Contact

Questions or privacy concerns can be raised through the public issue tracker:
